## Reading conventions

- **S** = selected operation; **E** = implied engineering operation; **O** = open/conditional variant. Status appears in the first column.
- **Public** means an external user-facing operation; **internal** means a suboperation, not a proposed public API. Several rows can compose into one atomic call.
- Uncertain table cells contain exactly **UNKNOWN**. A populated cell records only supported facts at the stated level; it does not claim a complete implementation formula. Cross-cutting gaps below identify missing details without inventing cell values.
- `DETF` = NET-DETF; `sDETF` = sNET-DETF staking receipt; `sNET` remains the external NetNet token. `HLP` = custom hook LP; `VLP` = canonical NET/USDG V2 LP; `PLP` = Pendle market LP. These are different tokens.
- Peg means NET per DETF. Ordinary hook swaps and standard-interface routing are different entry contexts. Hook-LP claims are not liquid-DETF reserve equity.

## Explicit gaps and boundaries

1. The source does not give a complete deploy/first-bond seed sequence, all HLP input/output variants, exact eligibility reference, curve-input mapping, fee ordering, self-leg treatment, USDG-bond release schedule, or detailed expansion/distribution formulas. UNKNOWN cells remain unfilled rather than importing unrelated family defaults.
2. Row 28's formula and row 34's conditional failure policies are identified in the prose because those cells otherwise record selected aspects. No exact numerical quote or new permission is implied. No user questions are added by this inventory.
3. Rows 22–24 distinguish funded staking rewards, released principal and combined retirement. The reference pays sDETF; final custom selector/recipient conventions and fraction retirement require specification. Native uncollected NET is not a reward payout. Retirement cannot erase later native installments.
4. ERC20/NFT standard behaviors are implied token-surface work, not approval for extra permit variants, enumerable APIs or administrator controls. V2 parity may include reference-specific modes; do not propagate those modes automatically onto every new contract. Hook/API exact-in/out variants must be enumerated in the final selector matrix.
5. NOT SELECTED: separate contraction/tender endpoint; unrestricted DETF LP redemption; automatic Universal fallback; arbitrary donation/rescue/sweep/pause/upgrade/admin-mint APIs; new wallet cooldown or actor restriction; deferred successful native harvesting; raw native-note payout; ordinary-no-YT routing for NET/sNET inputs; silently substituting a new Weighted invariant or bond formula.
6. Tax/rebasing authority conflict, source/deployment pins, note-array gas liveness and coupling/quote proofs remain blockers. No proof is provided by this table. Ordinary NET/sNET swap non-drainage must not be applied as a new restriction on legitimate HLP component exits or conflated with the owned-reserve contraction book.
7. No new external API claims required Context7 in this pass. No tests, commands, deployments or implementation changes were executed. Only this assigned research artifact was authored.
