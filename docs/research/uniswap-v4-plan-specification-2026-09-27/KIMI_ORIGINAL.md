## 2. Derivations (item 2 — derived from current requirements and implementation semantics; algebraic confidence noted; integer/domain validation is a §6 gate, not claimed here)

Common single-segment swap identities (vault sells token1 exact-in `s`): `u1 = u0 + φ·s/l`; `out0 = l(1/u0 − 1/u1)`; vault LP-fee accrual `ΔE1` = per `UniswapV4Quoter._creditInsideFees` (`UniswapV4Quoter.sol:214-226`, protocol-fee-netted). Pons: `φ = 1` and `out0 → out0·(1−c)` with floors. Mirrors for the other direction.

### 2.1 DER-1 — blocked single-exit inverse (replaces bisection)
Forward (`_singleExit`, reals): `out = R·r(2−r)`, `r = s/S` ⇒ `r* = 1 − √(1 − out/R)`. Integer protocol: `rad = floor(S²·(R − out)/R)`; `s0 = S − floorSqrt(rad)`; then minimal-adjust: `while forward(s0) < out: s0++`; `while forward(s0−1) ≥ out: s0−−` (each forward eval = the exact integer `_singleExit`). Domain: `0 < out ≤ R`; `R_other == 0` → linear `ceil(out·S/R)`; `R == 0` → infeasible (`InsufficientBacking`, existing error). **Confidence: high** (algebra + exact integer verification by construction).

### 2.2 DER-2 — idle zap-out exact-out shares
Mirror of execution (`OutExecutionDelegate.sol:108-147`): burn `δL = floor(s·L/S)`, free portions `floor(F_i·s/S)`, swap other leg exact-in. With `P = (L(1/u0 − 1/√b) + F_0)/S`, `m = (L(u0 − √a) + F_1)/S`, `k = φ/l`, `Q = φ·m/u0` (Pons: ×(1−c)):
`X(s) = P·s + Q·s/(u0 + k·m·s) = target` ⇒ **quadratic** `P·k·m·s² + (P·u0 + Q − target·k·m)·s − target·u0 = 0`. Integer: ceil positive root; forward-verify `X(ŝ)` with execution floors; require `X(ŝ) ≥ target > X(ŝ−1)`; pay exactly `target`; surplus booked (existing D55 semantics, `OutExecutionDelegate.sol:78-81`). Domain: `l > 0`; zero initialized-tick crossings over `u0→u1(ŝ)` (bounded bitmap reads); `ŝ ≤ maxShares`. **Confidence: high structure; coefficient-level overflow analysis pending (gate).**

### 2.3 DER-3 — idle exact-shares mint input (token1-in; mirror for token0)
Issuance identity at aligned ratios: `S·out0 = S_out·B_0'`, with `B_0' = L(1/u1 − 1/√b) + F_0` (E₀=0 after route-start collection, §6 ordering). Multiplying by `u1` makes this **linear**:
`u1* = (S·l + S_out·L) / (S·l/u0 + S_out·(L/√b − F_0))`. Require denominator > 0, `u1* ∈ (u0, u_cap]`, segment check. Then `s* = l(u1* − u0)/φ`, `out0* = l(1/u0 − 1/u1*)` (Pons: ×(1−c)), incumbent `B_1' = L(u1* − √a) + F_1 + ΔE_1`, caller input `d = s* + out0*·B_1'/B_0'` → `d̂ = ceil(d)`. Execute; verify `min(floor(S·C_0/B_0'), floor(S·C_1/B_1')) ≥ S_out`; mint exactly `S_out`; rounding surplus to holders (existing semantics, `OutExecuteTarget.sol:105-137`). Funding keeps the existing `prepaidCredit` exclusion (`OutBase.sol:54-62`) — it *is* the required "backing excludes in-flight caller input" attribution (§6.1/§6.3). **Confidence: high structure; per above gate.**

### 2.4 DER-5 — deposit composition swap size (exact-in `d` given; bounded solver permitted, §6.4:233)
Condition `C_0·B_1' = C_1·B_0'` with `C_0 = l(1/u0 − 1/u1)` (Pons ×(1−c)), `C_1 = d − l(u1 − u0)/φ`, `B_0', B_1'` as in 2.3. All terms linear in `u1` after ×`u1` ⇒ **quadratic in u1** (coefficient table to be regenerated with overflow analysis in implementation; structure verified twice in-session). Root in `(u0, min(u_cap(50 bp), u_segmentMax)]`, `s ≤ d`. If the segment check fails: refinement only — ≤8 `UniswapV4Quoter.quoteFromState` probes on the monotone residual `g(s) = callerRatio(s) − bookRatio(s)` (unique root: caller ratio increasing, book ratio decreasing in `s`), `MAX_QUOTER_SWAP_STEPS = 64`; exhaustion → atomic revert `UniswapV4Exchange_UnsupportedRoute()` (existing error, `Common.sol:307`). **Confidence: high structure.**

### 2.5 DER-4 — combined maintenance (joint proportionality + sleeve solve; also the public-rebalance step)
Unknowns: holder swap `s`, placement `δ`. Post-swap free `F_0' = F_0 + l(1/u0 − 1/u1)`, `F_1' = F_1 − s`; targets `t_i = q·(D_i(u1) + F_i')`. Exact joint solve requires `(F_i' − t_i)` parallel to placement direction `(1/u1 − 1/√b, u1 − √a)` ⇒ **quadratic in u1**:
`(A_0 − B_1/√b)·u1² + (B_1 + A_1/√b − A_0·√a − B_0)·u1 + (B_0·√a − A_1) = 0`, with
`A_0 = (1−q)(F_0 + l/u0) + qL/√b`, `B_0 = (1−q)·l + qL`, `A_1 = (1−q)(F_1 + l·u0/φ) + qL·√a`, `B_1 = (1−q)·l/φ + qL`.
Then `s = l(u1* − u0)/φ`, `δ = (F_0' − t_0)/(1/u1* − 1/√b)` (sign selects add/remove; mirror for the opposite orientation; orientation chosen by residual signs). Clamps (all closed-form boundaries): price-impact cap `u1 ≤ u0·√(1 + cap)` (25 bp maintenance / 50 bp composition), `s ≤ F_sell`, `−L ≤ δ`, root within segment. Infeasible-exact → boundary-clamped best step (public rebalance; §8 bounded work) or the route-level fallback of §1.2. **Confidence: structure verified; coefficient regeneration + differential testing is a gate.**

## 3. Accounting sequence and numerical/progress metrics (item 2 continued)

**Every idle money route (both families), ordered:** (1) establish caller credit (`_secureTokenTransfer`, `Common.sol:1219-1240` — guard + reserve-delta preserved per D15/§12) **before** fee collection (§6.1); (2) `_collectManagedFeesIfIdle()` (E→F once, §5:152); (3) user leg per §1; (4) measure actual received + incumbent position changes (incumbent-owned, §6.2:179); (5) placement (deposit route) / DER-4 maintenance (exact-out combined routes); (6) mint/pay; (7) protection checks; (8) `_syncVaultReserves()` full local booking (D16; `Common.sol:610-617` preserved); (9) events; (10) `_pokeBoundPoolTwap()`.

**Metrics (exact definitions):**
- Depositor alignment/loss: `ε_i = 1 − FullMath.mulDiv(sharesOut, B_i', S·C_i)`; require `ε_i ≤ 1e14` (1 bp WAD) for both `i`; `S·C_i == 0` unreachable outside activation (guarded). Separate from sleeve deadband (acceptance 11).
- Maintenance proportionality (D21): required per-unit-liquidity ratio at current price `a(u) = (1/u − 1/√b, u − √a)`; `mismatch = |F_0·a_1 − F_1·a_0| / (T_0·a_1 + T_1·a_0)` (FullMath, zero-denominator → only satisfied when both legs are zero) — sufficient iff `≤ 1e14`. Distinct from ε and from the sleeve deadband `max(floor_i, 5%·targetFree_i)` (`_absoluteFloor`, `Common.sol:362-370`).
- Progress (§8:301-302): `J = max(mismatch/1e14, |R_0|/db_0, |R_1|/db_1)`, `R_i = F_i − targetFree_i`; a step executes only if the closed-form post-state has `J' < J` strictly **after** modeled costs/placement; else truthful no-op (`false` return + sync, existing shape `Common.sol:763-766,802-806`). Partial progress + immediate successive calls per D10/D11.
- Impact per swap leg: `|u1² − u0²|·1e18/u0²` (price, not sqrt-price, §9:319-325) ≤ 25 bp (maintenance) / 50 bp (composition).
- Shortfall: measured actual vs fee-inclusive modeled amount ≤ 10 bp; the model already nets LP+protocol+hook cuts — no second subtraction (§9:327).
- Sleeve target: `targetFree_i = floor(T_i·p/(1e18+p))` — replaces `Common.sol:358-360,744-749` percent-of-total; live read each route; stored-zero fallthrough preserved.
**Protection constants:** `internal constant` per family (D25): `REBALANCE_MAX_PRICE_IMPACT_WAD = 0.0025e18`, `COMPOSITION_MAX_PRICE_IMPACT_WAD = 0.005e18`, `MAX_EXECUTION_SHORTFALL_WAD = 0.001e18`, `MAX_ALIGNMENT_LOSS_WAD = 0.0001e18`, `MAX_COMPOSITION_QUOTER_PROBES = 8`, `MAX_QUOTER_SWAP_STEPS = 64`.
