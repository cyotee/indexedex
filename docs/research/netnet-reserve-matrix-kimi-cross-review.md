## 4. LP-share withdrawal vs swap conversion — the entitlement clarification

The owner's two matrices define **two disjoint surfaces**:
- **HLP exit (custody surface):** pays **raw components per included leg** — raw DETF, raw SE shares, raw SY, and sub-reserve-derived SY via the exit quote. O:9–11's "withdrawals **including this leg** receive proportional …" implies **subset exits are contemplated**: each included leg pays its `h/H` proportional raw amount; non-included legs are untouched. No USDG/sNET/NET conversion occurs inside an HLP exit.
- **Public swap surface (pricing surface):** virtual balances — USDG via SE rate provider on held shares (USDG out redeems from the SE), sNET via SY interest expressed on redemption, NET via amount-specific PLP/YT zap-out. These are the only places underlying conversion happens.
- **Residual ambiguity (genuine):** v0.20 selected Weighted **invariant-priced** unbalanced/subset/single-token exits paying NET/sNET/USDG/DETF (P:175,348,802). The owner's matrix describes raw proportional payout per included leg. Whether converted single-token HLP exits survive alongside raw proportional/subset payout — or exits become raw-component-only with all conversion pushed to the swap surface — is not decided by O and must not be inferred. HLP ownership preservation is unaffected either way: exits debit only owned HLP and its `h/H` component claims; the DETF's owned fraction remains the burn/reinvestment domain (P:182).
