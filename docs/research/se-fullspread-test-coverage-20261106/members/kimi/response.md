## Assumptions

- The 2026-11-06 owner lock controls the gaps it names. Elsewhere, silence in RP does not remove an FP or PRD obligation.
- Exact-input directions are `zeroForOne` and `oneForZero`, with the token at each end determined by address sorting. Naming a direction does not assume that a particular token is always currency0.
- Preview equality concerns the output word or output array required by the sources. `amountRefunded` is not required to be bit-equal to execution merely because `amountOut` is; positional shape and expressly required zero refunds remain assertions.
- A recorded integration rejection is not a passing conversion proof. A gas overflow is unresolved, not a pass.
