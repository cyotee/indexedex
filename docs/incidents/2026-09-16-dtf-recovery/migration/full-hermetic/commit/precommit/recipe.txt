Precommit inventory recipe v1
Captured before staging or committing the full-hermetic metadata correction.
The walks completed before any file existed under migration/full-hermetic/commit/.
Inventory files written afterward are excluded evidence and are not members of the preservation set.
No build, deletion, chmod, cache write, artifact restoration, relocation, or runtime rerun is part of this recipe.
Every Git invocation uses GIT_MASTER=1 and --no-pager. GIT_PAGER=cat and PAGER=cat are set.
Read-only Git invocations also set GIT_OPTIONAL_LOCKS=0 so they do not refresh the index.
Status and diff use --ignore-submodules=all.
Index identity is the SHA-256 of the raw index file bytes. It is not git ls-files output and not a decoded string.

Content inventory
Files: docs-incidents.jsonl, out.jsonl, cache_forge.jsonl.
Walk: lstat, followlinks false. Symlinked directories are recorded and not descended. Ordinary directories are not content entries.
Fields, fixed key order: path, kind, gitMode, perm, st_mode, size, sha256, target.
path: POSIX relative to the worktree, sorted by UTF-8 byte order, which equals Unicode code point order for these paths.
kind: file, symlink, or other.
gitMode: 100644 regular non-executable, 100755 regular executable, 120000 symlink, 000000 other. This collapses exact regular-file modes and is not the permission proof.
perm: oct(st_mode & 0o777), written as 0o644 style text.
st_mode: full lstat mode integer, for example 33188.
size: lstat st_size.
sha256: SHA-256 of file bytes for regular files; SHA-256 of the symlink target string encoded UTF-8 for symlinks; null otherwise.
target: symlink target string, else null.
Serialization: UTF-8 JSON Lines, JSON.stringify key order as listed, one record per line, each line ending in \n, no extra trailing blank line.
Aggregate SHA-256 is SHA-256 of those exact JSONL bytes and is not a substitute for the rows.

Permission inventory
Files: docs-incidents-perms.jsonl, out-perms.jsonl, cache_forge-perms.jsonl.
Same roots. Ordinary directories are included, including the walk root. Directory paths have no trailing slash.
Fields, fixed key order: path, kind, perm, st_mode, size, sha256, target.
Directory sha256 is null. File and symlink sha256 use the same rules as the content inventory.
The post-commit permission pass did not recompute file sha256. A raw comparison that leaves actual sha256 null is not a change finding. The content inventory rehash is the byte proof. Directory rows are proved by kind, perm, st_mode, and size.
