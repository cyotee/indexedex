Drill-down · SE vault

Double-sided LP, zap in, zap out

The SE vault keeps both $DTF and ETH in the Uniswap V4 book so it earns pool swap fees. A single-token deposit is a zap in. Redeeming vault shares is a zap out. That is cheaper than buying the full amount on the pool, because a withdraw already returns part of the token you want.

One token in, one token out

Deposit · zap in

Pay one token, mint shares

$DTF in → sell some $DTF for ETH → add $DTF + ETH to the pool → mint SE vault shares

Same path if you pay ETH. The vault does not sit on a single-asset pile. It zaps into both sides.

Redeem · zap out

Burn shares, take one token

Burn shares → withdraw $DTF + ETH from the pool → swap the other side if needed → pay one token

The quote is a zap out. You are not owed a full buy on the pool. You are owed a withdraw, then only the leftover trade.
