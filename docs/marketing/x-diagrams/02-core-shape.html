Inside a DETF

Token, reserve, vaults

The DETF token is the contract. Behind it is a reserve: the assets that back the token. Vaults underneath run the legs of the basket.

IndexedEx

DETF token

The diamond is the token

Mint, burn, and bond happen here. People trade this token. There is no separate share contract.

Reserve

The assets behind the token

A pool that holds the DETF itself plus vault shares. Putting the DETF in that market is how the reserve is managed.

DETF in the pool The token’s own market leg
Vault shares Receipts from the vaults in the basket

Vaults

Where the basket works

Each vault holds and moves the underlying tokens. Earn vaults are building blocks a DETF can put in its basket.
