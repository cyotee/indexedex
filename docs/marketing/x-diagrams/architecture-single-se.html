Example: $DTF / ETH Single SE DETF

Components and who holds what

Bottom: a Uniswap V4 $DTF / ETH pool, and an SE vault that holds that LP. Middle: the DETF reserve is another Uniswap V4 pool ($DTF / $DTF-DETF) whose hook keeps $DTF in the SE vault and prices the vault token as $DTF. Top: the Bond NFT owns the reserve LP. The DETF token and the rebasing claim talk to that NFT.

IndexedEx

Contracts people call

DETF token

$DTF-DETF

The DETF contract. Facade in front of the Bond NFT. Mint, burn, and bond go here. It tells the Bond NFT to deposit or withdraw reserve LP.

Rebasing claim token

Owns Bond NFT ID 0

ID 0 is the protocol bond. The rebasing token uses that ID to tell the Bond NFT how to touch protocol-owned liquidity.

User bonds

Bond NFTs, IDs 1+

Each lock is an NFT. Principal is reserve LP. Rewards accrue on the NFT. Claim takes DETF. It does not cash the principal.

calls deposit / withdraw LP

Owns the reserve liquidity

Bond NFT vault

Holds hook LP

The Bond NFT actually owns the reserve pool LP. Token ID 0 is protocol. User IDs are 1+. The DETF never sits on the LP itself.

Uniswap V4 pool

$DTF ↔ $DTF-DETF

What Uniswap lists as the reserve pool. The hook is this pool’s hook. Swaps are $DTF against the DETF token.

Buffer hook

Holds the SE vault token

Incoming $DTF is deposited into the configured SE vault. $DTF-DETF stays as raw inventory. Rate provider prices the SE vault token as $DTF, so the book is $DTF vs $DTF-DETF.

$DTF side is the SE vault token. Hook deposits $DTF into the vault.
