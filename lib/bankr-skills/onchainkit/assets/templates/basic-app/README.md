# Basic OnchainKit App Template

A standalone Next.js Pages Router starter with React 19 and OnchainKit 1.1.
Includes real wallet connection, identity display, chain reads, and message signing.

## Quick start

Use Node.js 22.13 or later (Node 22 LTS recommended) and npm.

1. Copy this whole directory, including dotfiles, to your project.
2. Run `npm ci` in the copied directory.
3. Optionally copy `.env.local.example` to `.env.local` and configure services.
4. Run `npm run dev` and open `http://localhost:3000`.

No keys or funds are required to build or open the app. Coinbase Wallet and
injected browser wallets (including MetaMask) are configured out of the box.
Without a browser wallet, its connection button reports a provider-not-found
error rather than silently succeeding.

## Working features

- Connect and disconnect Coinbase Wallet or an injected browser wallet.
- Enable WalletConnect QR/mobile connections with `NEXT_PUBLIC_WC_PROJECT_ID`.
  Register your app origin in the Reown dashboard.
- Display an OnchainKit avatar, ENS/Basename when available, and the full address.
  Identity resolution uses Base mainnet even when the activity chain is Base
  Sepolia. Public identity services can require a browser-safe CDP API key or
  return no name/avatar; the address remains visible.
- Read the selected chain's latest block and the connected address's ETH
  balance. Refresh explicitly; RPC failures are visible and recoverable.
- Switch a connected wallet to the configured chain.
- Sign the displayed greeting using `personal_sign`. Rejection is shown in the
  UI. The resulting signature is displayed locally, not submitted anywhere.
  This is a signing example, **not authentication**: there is no server,
  nonce, session, or replay protection.
- Responsive layout, automatic light/dark themes, and strict TypeScript.

The starter does not request token approvals, transfers, or other transactions.
Use a disposable wallet on Base Sepolia when exploring extensions.

## Configuration

All `NEXT_PUBLIC_*` values are public browser build-time configuration. Never
put secret keys in them. Restart dev or rebuild after changing them.

| Variable | Default / purpose |
| --- | --- |
| `NEXT_PUBLIC_CDP_API_KEY` | Optional browser-safe CDP key for identity services; restrict allowed origins |
| `NEXT_PUBLIC_WC_PROJECT_ID` | Optional Reown project ID; connector omitted if empty |
| `NEXT_PUBLIC_CHAIN_ID` | `8453` (Base); also supports `84532` (Base Sepolia); other values fail explicitly |
| `NEXT_PUBLIC_RPC_URL` | Optional selected-chain RPC; otherwise viem's public RPC |
| `NEXT_PUBLIC_ONCHAINKIT_ANALYTICS` | Off unless exactly `true` |
| `NEXT_PUBLIC_APP_NAME` | `My OnchainKit App` |
| `NEXT_PUBLIC_APP_DESCRIPTION` | Intro and page description |

Public RPCs and identity services are rate limited. Configure a browser-safe
dedicated RPC for production. No credentials are bundled in this template.

## Validation

```sh
npm ci
npm run validate       # ESLint + TypeScript, not the old placeholder
npm audit
npm run build
npm start             # Production server, port 3000
```

`next lint` was removed in modern Next.js; `lint` invokes ESLint directly.
Next.js and its ESLint configuration are updated together. React and React DOM
must remain on React 19 to satisfy OnchainKit's peer contract. Commit lockfile
updates when intentionally changing dependencies; do not use legacy-peer-deps.
The scoped overrides keep Valtio's external-store shim compatible with React 19
and remove affected ws 8.x versions without changing its major API.
`typescript-eslint` is pinned to the consistently published 8.71.2 family;
8.72.0's umbrella package referenced an unpublished plugin at repair time.

OnchainKit 1.1.3 is deprecated upstream but retained here by owner decision.
The npm audit may still report transitive issues in its legacy wallet/miniapp
dependency graph and in the lint toolchain. Do not force-downgrade OnchainKit
or migrate wagmi to v3 merely to silence inherited findings: that violates
OnchainKit's v2 peer contract. Review the current audit when deploying.

For browser checks, verify both disconnected and connected states at desktop
and phone widths, network mismatch/switch, rejected and successful signatures,
disconnect, and RPC errors/recovery. A synthetic injected EIP-1193 wallet can
exercise these without real funds or external writes. Real Coinbase Wallet,
MetaMask extension, WalletConnect relay, and CDP credential checks require the
corresponding installed wallet/service configuration.

## Extending

Add OnchainKit Swap, NFT, Transaction, or Checkout components to the page as
needed; these are extension points, not bundled demo claims. Keep the wagmi,
React Query and OnchainKit provider order. To add chains, update both the
explicit chain validation and wagmi transports in `lib/wagmi.ts`.
