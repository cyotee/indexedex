# Design spec

Lane: no-format
Lineage: inline
Palette: neutral text on white, one accent #1f4e79 for table headers.
Type: system sans. No emoji.
Figures: one comparison table is the required visual. Caption it. Do not stretch it.
Citations: [S<n>] next to each mechanism claim.
Closing: short method note and numbered sources with access date 2026-10-23.
