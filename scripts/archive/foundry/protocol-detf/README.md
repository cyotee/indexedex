# Archived Protocol DETF deploy scripts

These scripts deployed the **deprecated Protocol DETF product**. They are preserved for history only and are **not** live ops paths.

Shared DETF surface is now `IDetf` (`contracts/interfaces/detf/IDetf.sol`). Bond NFT and rebasing claim packages live under `contracts/vaults/detf/common/bondNft/` and `contracts/vaults/detf/common/claimToken/`.

Do not run these scripts against current packages; package paths and product types they reference no longer exist as a live product family.
